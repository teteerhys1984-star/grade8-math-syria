# رياضيات الصف الثامن — المنهاج السوري

هيكل قابل للتوسع لموقع دروس الرياضيات. الواجهة مبنية بـ Vite وJavaScript وCSS دون إطار عمل، مع تنقل hash مناسب للاستضافة الثابتة.

## التشغيل

```bash
npm install
npm run dev
```

## بنية المحتوى

- `src/data/content.js`: المصدر المستقل لبيانات قسمي الجبر والهندسة.
- كل قسم يملك قائمة `lessons` مستقلة.
- كل درس يملك `number` و`title` و`description` و`topics`.
- كل موضوع يحدد تبويبه بنفسه، ويمكنه حمل `explanation` و`examples` و`notes` و`commonMistakes` و`exercises` و`interactions` و`assessment`.
- `assessment` جزء من بيانات الدرس، ويدعم إعدادات إظهار التغذية الراجعة وإعادة الاختبار والنتيجة النهائية.
- `questionTypes` يحدد أنواع الأسئلة المدعومة مستقبلًا: اختيار من متعدد، رقمي، نصي، صح/خطأ، ترتيب خطوات، مطابقة، وأسئلة رياضية تفاعلية.

البيانات الحالية تجريبية ومحدودة للتحقق من البنية فقط، وليست محتوى من المنهاج. لإضافة درس حقيقي، أضفه إلى `algebraLessons` أو `geometryLessons` مع تبويباته الخاصة دون تعديل نظام العرض أو التنقل.

المعادلات المستقبلية يجب أن تُخزّن بصيغة عرض مناسبة مثل MathML داخل بيانات المحتوى، لا كنص LaTeX ظاهر للطالب.
