# رياضيات الصف الثامن — المنهاج السوري

هيكل أولي قابل للتوسع لموقع دروس الرياضيات. الواجهة مبنية بـ Vite وJavaScript وCSS دون إطار عمل، مع تنقل hash بسيط يحافظ على قابلية الاستضافة الثابتة.

## التشغيل

```bash
npm install
npm run dev
```

بيانات الأقسام والدروس موجودة في `src/main.js`، ويمكن استبدال القوالب الوهمية بمحتوى الدروس لاحقًا مع الحفاظ على بنية التنقل والتبويبات.
